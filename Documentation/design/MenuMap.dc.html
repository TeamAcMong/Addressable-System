Everything reachable two ways
A menu item and a place inside the window. The menu is the shortcut; the window is the home. Nothing lives only in a menu.
Destructive actions leave the menu
"Clear All Caches" and "Force Process All Assets" sat one slip away from Dashboard. They move inside, behind the state they affect and a confirmation that names what is lost.
Create menus point at real paths
"Create Debug Settings" writes to Assets/, and the loader only ever reads Resources/AddressableManager/. It now creates the folder and writes where the loader looks.
