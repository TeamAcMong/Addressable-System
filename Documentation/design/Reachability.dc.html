Can we reach the CDN, and is it newer?
Today this question can only be asked from play mode, through CdnManager.CheckForUpdateAsync, after the game has initialised the CDN layer — so testing a piece of infrastructure requires running the game. The Editor assembly has never made an outbound request; the only thing that asks a CDN anything is ci/verify-urls.sh, which is curl in a shell nobody can press from inside Unity. This block goes on Catalog Inspector, the one screen that already holds the local half of the comparison.
Four outcomes, not two
“Up to date” and “could not ask” look identical on a screen that only has a green tick and a red cross, and they are opposites: one means the content is current, the other means nobody knows. The runtime already carries this distinction as WasOfflineFallback — the Editor must not throw it away. A refused request is a fifth thing again: the CDN answered, and said no.
